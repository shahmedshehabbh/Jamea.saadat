# جامع السعادات - مكتبة المحاضرات الرقمية

![Version](https://img.shields.io/badge/Version-1.0.0-blue)
![License](https://img.shields.io/badge/License-MIT-green)
![Arabic](https://img.shields.io/badge/Arabic-RTL-orange)

مكتبة رقمية متكاملة لجمع وعرض محاضرات وشروحات كتاب **جامع السعادات** للعلامة المحقق المولى مهدي النراقي.

## ✨ المميزات

- 📚 **مكتبة شاملة**: تنظيم المحاضرات حسب الفصول والمشايخ
- 🎬 **أنواع متعددة**: دعم المواد المرئية والصوتية والنصية
- 🔍 **بحث متقدم**: بحث وتصفية سريعة حسب العنوان والشيخ والفئة
- ➕ **إضافة سهلة**: واجهة إدارة بسيطة لإضافة محاضرات جديدة
- 📱 **متجاوب**: يعمل على جميع الأجهزة (Desktop, Tablet, Mobile)
- 💾 **تخزين محلي**: حفظ البيانات في localStorage
- 🎨 **تصميم عصري**: واجهة احترافية باللغة العربية

## 🚀 التشغيل السريع

### المتطلبات
- متصفح حديث (Chrome, Firefox, Safari, Edge)
- Python 3.x أو Node.js (لتشغيل السيرفر المحلي)

### طريقة التشغيل

#### باستخدام Python:
```bash
cd "Website Saadat"
python -m http.server 8000
```

#### باستخدام Node.js:
```bash
cd "Website Saadat"
npx http-server -p 8000
```

ثم افتح المتصفح على: `http://localhost:8000`

## 🎯 طريقة الاستخدام

### إضافة محاضرة جديدة:
1. اضغط على الزر الذهبي **＋** في الزاوية السفلى اليسرى
2. املأ معلومات المحاضرة:
   - عنوان المادة (مطلوب)
   - اسم الشيخ (مطلوب)
   - النوع: مرئية / صوتية / نصية
   - الوصف (مطلوب)
   - معلومات إضافية (اختيارية)
3. اضغط **💾 حفظ المادة**
4. ستظهر المحاضرة مباشرة في الصفحة!

### البحث والتصفية:
- استخدم شريط البحث للبحث بالعنوان أو الشيخ
- صفّي حسب النوع (مرئية/صوتية/نصية)
- صفّي حسب التصنيف
- رتّب النتائج (الأحدث/الأقدم/أبجدياً)

### عرض التفاصيل:
- اضغط على أي بطاقة محاضرة
- شاهد التفاصيل الكاملة
- استمع للصوت أو شاهد الفيديو
- تصفح المحاضرات ذات الصلة

## 📖 عن كتاب جامع السعادات

**المؤلف**: العلامة المحقق المولى مهدي النراقي (١١٢٨ - ١٢٠٩ هـ)

كتاب جامع السعادات من أجمع كتب الأخلاق الإسلامية، يقع في ثلاثة أجزاء يتناول فيها المؤلف علم الأخلاق بمنهج فلسفي تحليلي دقيق.

### محاور الكتاب:
- تعريف علم الأخلاق وموضوعه
- القوى النفسية الثلاث (العقلية، الغضبية، الشهوية)
- الفضائل الأخلاقية الأربع (الحكمة، الشجاعة، العفة، العدالة)
- الرذائل الأخلاقية وطرق معالجتها
- السلوك العملي نحو كمال النفس
