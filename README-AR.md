# 📚 موقع جامع السعادات - دليل الاستخدام الشامل

## 🎯 نظرة عامة

موقع **جامع السعادات** هو مكتبة رقمية متكاملة لإدارة وعرض المحاضرات والدروس الخاصة بشرح كتاب جامع السعادات للعلامة النراقي.

## ✨ المميزات الرئيسية

✅ **واجهة عربية احترافية** - تصميم حديث وسهل الاستخدام  
✅ **نظام إدارة المحتوى** - إضافة المواد مباشرة من المتصفح  
✅ **دعم متعدد الوسائط** - فيديو، صوت، نصوص، مقاطع قصيرة  
✅ **بحث وتصفية متقدمة** - البحث بالعنوان، الشيخ، الفصل  
✅ **تخزين مشترك** - تُحفظ المحاضرات في Supabase وتظهر لجميع الزوار  
✅ **متوافق مع الجوال** - Responsive Design  
✅ **دخول المشرف** - حسابات Supabase مع صلاحية مشرف محمية بسياسات RLS

## 🚀 كيفية الاستخدام

### 1️⃣ فتح الموقع
- افتح ملف `index.html` مباشرة في المتصفح (Chrome, Firefox, Edge)
- أو استخدم أي خادم محلي (Live Server في VS Code)

### 2️⃣ إضافة مادة جديدة

1. سجّل الدخول من **دخول المشرف** باستخدام حساب المشرف في Supabase، ثم انقر على الزر **＋** الذهبي في أسفل يسار الشاشة.
2. املأ النموذج بالتفاصيل:
   - **عنوان المادة** (إجباري)
   - **اسم الشيخ** (إجباري)
   - **التاريخ** (اختياري)
   - **نوع المادة**: مرئية، صوتية، نصية، مقطع
   - **التصنيف**: مقدمة، شرح جامع السعادات، فضائل، رذائل
   - **وصف مختصر** (إجباري)
   - **الملخص الكامل** (اختياري)
   - **أبرز النقاط** (كل نقطة في سطر منفصل)
   - **رابط الفيديو** (YouTube embed أو رابط مباشر)
   - **رابط الصوت** (MP3 أو رابط مباشر)
   - **رابط الصورة المصغرة**
   - **الكلمات المفتاحية**
3. في خانة **الملخص الكامل** استخدم شريط التنسيق لإضافة العناوين، والخط العريض أو المائل، والقوائم، والاقتباسات، والروابط. تعرض المعاينة شكل الملخص قبل الحفظ.
   - اضغط **🖼️ صورة** للوصول إلى حقلي رابط الصورة ووصفها، ثم اضغط **إدراج الصورة في الملخص**.
   - يجب أن يبدأ رابط الصورة بـ `https://` أو `http://`، وتظهر الصورة ضمن الملخص بعد الحفظ.
4. انقر على **💾 حفظ المادة**. يتطلب الحفظ المشترك إعداد Supabase وتسجيل دخول المشرف.
5. ستظهر المادة فوراً في الموقع.

### 3️⃣ البحث والتصفية

**البحث النصي:**
- استخدم مربع البحث في الصفحة الرئيسية أو صفحة الأرشيف
- يبحث في العنوان، الشيخ، الفصل، الكلمات المفتاحية

**الفلترة:**
- **حسب النوع**: مرئية، صوتية، نصية، مقاطع
- **حسب الفصل**: مقدمة، شرح، فضائل، رذائل
- **الترتيب**: الأحدث، الأقدم، أبجدي

**الفلاتر السريعة:**
- انقر على الأيقونات الملونة (🎬 🎧 📖 ✂️) للتصفية الفورية

### 4️⃣ عرض تفاصيل المحاضرة

- انقر على **عرض المحاضرة ←** في أي بطاقة
- لكل محاضرة رابط مستقل يمكن مشاركته، مثل:
  `https://example.com/index.html#lecture/1`
- يمكن للمشرف نسخ الرابط من زر **📋 نسخ الرابط** داخل صفحة تفاصيل المحاضرة
- ستفتح صفحة تفاصيل كاملة تحتوي على:
  - مشغل الفيديو/الصوت (إن وُجد)
  - ملخص المحاضرة
  - أبرز النقاط
  - معلومات تفصيلية
  - محاضرات ذات صلة

### 5️⃣ الروابط الخاصة بالمحاضرات

يتم إنشاء الرابط تلقائياً اعتماداً على رقم المادة:

```text
index.html#lecture/رقم-المادة
```

عند فتح الرابط مباشرة، يعرض الموقع المحاضرة المطلوبة بدلاً من الصفحة الرئيسية. مع إعداد Supabase
تُحمّل المادة من الجدول المشترك؛ أما من دون الإعداد فيخص التخزين المحلي المتصفح الحالي فقط.

## 💾 إدارة البيانات

### إعداد Supabase (مطلوب للتخزين المشترك)

1. أنشئ مشروعاً في [Supabase](https://supabase.com/) وافتح **SQL Editor**.
2. أنشئ جدول المحاضرات وسياسات الوصول بتشغيل SQL التالي:

```sql
create table public.lectures (
  id bigint generated by default as identity primary key,
  title text not null,
  speaker text not null,
  date text not null default '',
  category text not null default '',
  type text not null,
  duration text not null default '',
  image text not null default '',
  description text not null default '',
  summary text not null default '',
  points jsonb not null default '[]'::jsonb,
  keywords text not null default '',
  video_url text not null default '',
  audio_url text not null default ''
);

alter table public.lectures enable row level security;

create policy "Anyone can read lectures"
  on public.lectures for select
  to anon, authenticated
  using (true);

create policy "Authenticated admins can add lectures"
  on public.lectures for insert
  to authenticated
  with check ((auth.jwt() -> 'app_metadata' ->> 'role') = 'admin');

create policy "Authenticated admins can edit lectures"
  on public.lectures for update
  to authenticated
  using ((auth.jwt() -> 'app_metadata' ->> 'role') = 'admin')
  with check ((auth.jwt() -> 'app_metadata' ->> 'role') = 'admin');

create policy "Authenticated admins can delete lectures"
  on public.lectures for delete
  to authenticated
  using ((auth.jwt() -> 'app_metadata' ->> 'role') = 'admin');
```

3. من **Project Settings → API** انسخ **Project URL** ومفتاح **anon/public** (أو **publishable**)، ثم انسخ `config.example.js` إلى `config.js` واملأ القيم:

```js
window.SUPABASE_CONFIG = {
  url: 'https://YOUR_PROJECT_REF.supabase.co',
  anonKey: 'YOUR_SUPABASE_ANON_OR_PUBLISHABLE_KEY'
};
```

`config.js` مستثنى من Git افتراضياً لتجنب رفعه قبل إعداده. المفتاح anon/publishable عام ومخصص للمتصفح؛ يمكن رفع ملف الإعداد إلى GitHub Pages بعد ملئه بمعلومات المشروع. تتحكم سياسات RLS بما يمكن لهذا المفتاح فعله. **لا تضع مفتاح `service_role` أو أي سر في ملفات الموقع.**

4. من **Authentication → Users** أنشئ حساباً لكل مشرف مع البريد الإلكتروني وكلمة المرور، ثم عيّن له دور المشرف server-controlled بتشغيل SQL التالي في **SQL Editor** (بدّل البريد):

```sql
update auth.users
set raw_app_meta_data = coalesce(raw_app_meta_data, '{}'::jsonb) || '{"role":"admin"}'::jsonb
where email = 'admin@example.com';
```

أوقف التسجيل العام للمستخدمين من إعدادات **Authentication**. سيمنع شرط RLS أي حساب لا يحمل `app_metadata.role = admin` من الإضافة أو التعديل أو الحذف، حتى لو تمكن مستخدم عادي من تسجيل الدخول. يسجل المشرف دخوله من رابط **دخول المشرف** باستخدام بيانات الحساب المنشأ في Supabase.

بعد تغيير الدور، سجّل الخروج والدخول مجدداً ليحصل الحساب على رمز دخول يتضمن الدور الجديد.
5. أضف المحاضرات الافتراضية الثلاث الموجودة في `DEFAULT_LECTURES` وأي بيانات محلية تريد الاحتفاظ بها إلى جدول `public.lectures` من لوحة Supabase أو استوردها كـCSV؛ لا تُزرع البيانات الافتراضية تلقائياً. المحاضرات التي أُنشئت سابقاً في `localStorage` تبقى على المتصفح الذي أنشأها ولا تُرفع تلقائياً، ويجب نقلها إلى الجدول لتصبح مشتركة.
6. إذا أدخلت أرقام `id` يدوياً أثناء الاستيراد، حدّث عدّاد الترقيم قبل إضافة مادة من الموقع لتجنب تكرار رقم موجود:

```sql
select setval(
  pg_get_serial_sequence('public.lectures', 'id'),
  coalesce((select max(id) from public.lectures), 1),
  exists(select 1 from public.lectures)
);
```

عند إعداد Supabase تُحمّل المحاضرات وتُضاف وتُعدّل وتُحذف مباشرة من الجدول المشترك. إذا لم يوجد `config.js` أو لم تُملأ قيمه، يعمل الموقع على بيانات التخزين المحلي لهذا المتصفح فقط ويعرض تنبيهاً واضحاً؛ لن تظهر هذه البيانات للزوار الآخرين، وتبقى عمليات الإدارة معطّلة حتى إعداد Supabase. أخطاء الاتصال أو سياسات RLS تُعرض للمستخدم ولا تتحول إلى حفظ محلي صامت.

## 🌐 النشر على الإنترنت

### الطريقة 1: GitHub Pages (مجاني)
1. أنشئ حساب على GitHub
2. أنشئ مستودع جديد (Repository)
3. ارفع الملفات: `index.html`, `style.css`, `app.js`، و`config.js`. يحتوي `config.js` على مفتاح anon/publishable العام المصمم للاستخدام في المتصفح، وليس مفتاحاً سرياً؛ إذا بقي مستثنى من Git بسبب `.gitignore`، أضفه باستخدام `git add -f config.js`.
4. في Settings → Pages → اختر branch: main
5. سيظهر رابط الموقع خلال دقائق

### الطريقة 2: Netlify (مجاني)
1. اذهب إلى netlify.com
2. اسحب مجلد المشروع مباشرة
3. سينشر الموقع فوراً

### الطريقة 3: Vercel (مجاني)
1. اذهب إلى vercel.com
2. استورد المشروع من GitHub
3. سينشر تلقائياً

## 🔧 استكشاف الأخطاء

### المشكلة: لا تظهر المحاضرات بعد الإضافة
**الحل**: 
- تأكد من تفعيل JavaScript
- افتح Console (F12) وتحقق من الأخطاء
- جرّب مسح Cache (Ctrl+Shift+R)

### المشكلة: الفيديو لا يعمل
**الحل**:
- تأكد من رابط الفيديو صحيح
- استخدم رابط embed من YouTube: 
  `https://www.youtube.com/embed/VIDEO_ID`
- تأكد من أن الفيديو غير محظور

### المشكلة: الصور لا تظهر
**الحل**:
- تأكد من رابط الصورة صحيح
- استخدم روابط تدعم HTTPS
- جرّب رابط من Unsplash أو Pexels
